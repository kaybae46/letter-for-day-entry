One letter, A to Z, standing for the word that describes the day — for make.fun's "One Letter for Your Day" bounty.

## The entry

**N — "no sleep".**

Tuesday 24 November 2026 was worked straight through the night: bounty builds, hourly Interstellar cache claims (00:12, 02:16, 04:17 WIB) and a make.fun screening sweep every five minutes, with no sleep in between. "No sleep" is the truest, most vivid word for the day, and N is its first letter.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes exactly one character, `N`, to `/output/entry.txt` — no trailing newline, no extra bytes. It is deterministic: every run writes the same byte, with no network access. It verifies the result itself and exits non-zero unless the file holds exactly one ASCII letter, A-Z.
